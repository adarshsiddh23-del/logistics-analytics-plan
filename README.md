# Logistics Analytics: Strategic Plan and Prototype
Week 1 task: demand forecasting, inventory policy and route optimization for a regional distribution network.

Run the prototype (synthetic data, no downloads needed):
    pip install -r requirements.txt
    python src/logistics_pipeline.py

Outputs: console metrics (MAE/MAPE, clusters, reorder points, route savings) and charts in figures/.
Report: Week1_Logistics_Strategic_Planning_Report.docx
